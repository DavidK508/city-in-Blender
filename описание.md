# Описание проекта

Процедурный генератор мегаполиса для Blender 5.x — вся сцена строится Python-скриптами в headless-режиме, воспроизводимо по сиду.

## Структура

| Путь | Что внутри |
|---|---|
| `run.py` | Точка входа для Blender (`blender --background --python run.py -- ...`) |
| `Makefile` | Команды: `make preview`, `preview-night`, `render`, `anim`, `save`, `clean` |
| `city/config.py` | Все параметры города (seed, размеры, этажность, рендер) |
| `city/roads.py` | Улицы (артерии + местные, с искривлением), тротуары, земля |
| `city/buildings.py` | Кварталы → лоты → здания: podium, сужение башен, антенны, высоты по расстоянию до центра |
| `city/materials.py` | Процедурные фасады; ночью — светящиеся окна (сетка brick + случайный шум) |
| `city/details.py` | Фонари, машины, деревья, парки |
| `city/lighting.py` | Небо+солнце (день) / луна+тёплые окна (ночь), bloom-композитор |
| `city/camera.py` | Статичный кадр или анимированный пролёт к даунтауну |
| `city/main.py` | CLI-флаги (`--night`, `--seed`, `--render`...), сборка сцены, рендер |
| `renders/` | Выход: `preview.png`, `preview_night.png`, `city.png`, `city_anim.mp4`, `city.blend` |
| `README.md` | Инструкция по запуску (EN) |

## Примеры запуска

```bash
make preview                                      # день, быстрое превью
make preview-night                                # ночь
make render                                       # финальный кадр 1920x1080
make anim                                         # пролёт камеры (250 кадров)
make save                                         # сохранить .blend

blender --background --python run.py -- --night --seed 7 --preview
blender --background --python run.py -- --anim --frames 50 --out renders/fly.mp4
```

## CLI-флаги

| Флаг | Описание |
|---|---|
| `--seed N` | Сид герерации (одинаковый seed → одинаковый город) |
| `--night` | Ночная сцена (светящиеся окна, фонари, bloom) |
| `--preview` | Быстрое превью с пониженным разрешением |
| `--render` | Финальный статичный кадр 1920x1080 |
| `--anim` | Анимация пролёта камеры от окраины к даунтауну |
| `--frames N` | Переопределить число кадров анимации |
| `--save` | Сохранить сцену в `renders/city.blend` |
| `--out PATH` | Свой путь вывода |
